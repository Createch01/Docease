# Tests manuels S1–S10 — sauvegarde obligatoire, motifs, reçus

Données de test : si possible une copie du dossier de données (`%LOCALAPPDATA%\com.docease.desktop`), à restaurer ensuite. Session médecin sauf mention.

| # | Étapes | Résultat attendu |
|---|--------|------------------|
| S1 | Médecin, aucune sauvegarde configurée : déverrouiller. | L'assistant « Protégez vos données » (étape 1 sur 3) s'ouvre ; bandeau rouge « Vos données ne sont pas sauvegardées » derrière. |
| S2 | Cliquer « Plus tard ». Naviguer entre plusieurs écrans. | L'assistant se ferme ; le bandeau rouge reste en haut de **chaque** écran. Verrouiller puis rouvrir la session : l'assistant revient. |
| S3 | Paramètres › Base de données : carte rouge « Aucune sauvegarde ». Cliquer « Configurer maintenant ». « Sauvegarder maintenant » est grisé avec une explication. | La page défile vers la phrase de passe, entourée d'un cadre rouge 2,5 s. |
| S4 | Dans l'assistant (ou la page) : phrase de 12 caractères, confirmation, case cochée, « Définir ». Fiche de secours proposée. Étape 2 : choisir un dossier **hors** du dossier de données, puis un second emplacement (clé USB / autre disque). Étape 3 : « Lancer la première sauvegarde ». | Bandeau rouge disparu ; carte verte « Dernière sauvegarde : à l'instant ✓ ». Un fichier `docease-AAAAMMJJ-HHMMSS.dcb` existe dans `DocEase-Sauvegardes` des deux emplacements. |
| S5 | Session assistante, sauvegarde non configurée (refaire S1 sur une copie vierge, ou supprimer `backup_meta.json` hors application, application fermée). | Bandeau rouge informatif « … ne sont pas sauvegardées. Prévenez le médecin. », **sans** bouton ni assistant, et aucun accès à Paramètres. |
| S6 | Bandeau orange : application fermée, éditer `last_success_at` de `backup_meta.json` à une date de plus de 3 jours (ou changer la date système de +4 jours), rouvrir. | Bandeau orange « La dernière sauvegarde réussie date de N jours » + « Sauvegarder maintenant » (médecin) ; après clic, bandeau disparu. Assistante : même bandeau orange avec « Prévenez le médecin ». |
| S7 | **Reprise de T7 pas à pas.** (1) Après S4, émettre une note d'honoraires, noter son numéro **N**, encaisser, émettre le reçu (noter **REC-N**), ajouter une dépense (noter **DEP-N**). (2) Paramètres › Base de données › « Sauvegarder maintenant ». (3) Émettre une 2ᵉ note (**N+1**) avec reçu (**REC-N+1**) et une 2ᵉ dépense (**DEP-N+1**). (4) Restaurer la sauvegarde de l'étape 2 (choisir la date, phrase de passe, taper RESTAURER). (5) Recharger. (6) Émettre une nouvelle note, un nouveau reçu, une nouvelle dépense. | La note de l'étape 3 n'est plus dans la liste (elle est postérieure à la sauvegarde). Les **nouveaux** numéros sont strictement supérieurs à N+1, REC-N+1 et DEP-N+1 (jamais réutilisés ; un trou dans la suite est normal et visible au contrôle de numérotation). Le registre des paiements contient encore l'encaissement de N+1 ; « Contrôler » (reçus, paiements, dépenses) : aucune anomalie bloquante sur les reçus et les paiements. |
| S8 | Paramètres › Cabinet › Identité professionnelle : renseigner « Nom en arabe », enregistrer. Imprimer une note d'honoraires et une ordonnance en arabe. | Le nom arabe imprimé est celui de l'identité. Une note déjà émise garde le nom arabe de son émission si on le change ensuite. |
| S9 | Mon design (ordonnance) : si un texte libre d'en-tête contient un autre nom (« Dr … » / « د. … »). | Avertissement orange « Nom différent de l'Identité professionnelle » dans la section En-tête, avec le texte en cause. |
| S10 | Motifs : annuler une note, une dépense ; corriger une dépense ; rembourser ; annuler/réémettre un reçu. | Liste déroulante des 6 motifs ; « Autre » demande ≥ 10 caractères (le bouton reste grisé) ; un motif d'une note déjà annulée reste affiché tel quel. |
| S11 | Reçu d'un encaissement existant : « Annuler (patient remboursé) ». | Refusé avec le message « atteste un encaissement toujours enregistré… Réémettre / Rembourser » ; aucun reçu créé, encaissement intact. |
| S12 | Même reçu : « Réémettre le reçu » (motif). | Nouveau reçu du même montant ; l'ancien passe à « Remplacé par REC-… » (imprimé : tampon REMPLACÉ) ; le registre des paiements est inchangé. Puis « Rembourser » le patient (motif) : le reçu valide peut alors être annulé. |
